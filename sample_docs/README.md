# Sample documents

Synthetic advising documents written for this repository. They describe a fictional,
unnamed graduate school, and every policy, deadline, fee, e-mail address and phone
number in them is made up (e-mail addresses use the reserved `example.edu` domain;
phone numbers use the fictional 555 range). They exist so the demo, tests and
evaluation have something to search.

To use gradguide for a real institution, point `GRADGUIDE_DOCS_DIR` at a folder of
that institution's own documents (Markdown, text, FAQ JSON/JSONL, HTML or PDF) and
optionally describe them in a `sources.toml` manifest like the one here.
